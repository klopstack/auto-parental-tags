Prompt Configuration

Customize the prompt sent to the AI. Available placeholders:
  • {itemType} - "movie" or "series" (lowercase)
  • {ItemType} - "Movie" or "Series" (capitalized)
  • {title} - Item title
  • {year} - Release year
  • {rating} - Official rating (PG, PG-13, etc.)
  • {genres} - Comma-separated genres
  • {studios} - Comma-separated studios
  • {tags} - Comma-separated existing item tags
  • {overview} - Plot summary
AI must respond with one of: kids, teens, family, or adults
Prompt template cannot be empty.
